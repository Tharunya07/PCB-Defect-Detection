About this defect:
{% if defect_class == 'missing_hole' %}

A missing hole defect occurs when a required hole in the PCB is not drilled or is blocked. This can prevent proper component mounting and electrical connections.

{% elif defect_class == 'mouse_bite' %}

Mouse bite defects appear as semi-circular nibbles taken out of the edges of conductors. These can weaken connections and cause future failures.

{% elif defect_class == 'open_circuit' %}

Open circuit defects represent broken connections in traces that should be continuous. This prevents electrical flow and causes circuit failure.

{% elif defect_class == 'short' %}

Short circuit defects occur when two conductors that should be separate are connected. This can cause improper current flow and damage components.

{% elif defect_class == 'spur' %}

Spur defects are small protrusions from a conductor. They can lead to short circuits, especially in high-density boards.

{% elif defect_class == 'spurious_copper' %}

Spurious copper defects are unwanted copper remnants in areas that should be clear. These can cause short circuits and interference.

{% endif %}
